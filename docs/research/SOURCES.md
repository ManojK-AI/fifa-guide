# Sources

**92 cited sources** across the research corpus, grouped by publisher and
ordered by evidential weight: EA's own pages first, then outlets reproducing EA's
notes, then reference sites, then community and opinion.

A further 96 URLs were encountered but not cited — search-result
listings, pages that were blocked or unreachable, and pages checked and rejected.
They are kept at the end so a later pass does not re-walk the same dead ends.

Generated from the citations in `agents/*.md` and `../legendary-playbook.md`.
Regenerate with `python docs/research/mksources.py` after adding research, so this
file never drifts from what the reports actually cite.

## How to weigh these

| Tier | Meaning | What it supports |
|---|---|---|
| **Primary (EA)** | EA Pitch Notes, update notes, settings guides | A claim may rest on this alone |
| **Patch reporting** | MP1st, SoccerGaming reproducing EA text | Dates, and EA text no longer live |
| **Reference sites** | FIFPlay, FIFAUTeam | Inputs and system values — spot-check; can carry stale rows |
| **Outlet guides** | Red Bull, RealSport101, Dexerto, EarlyGame, Sportskeeda | Settings opinion, not fact |
| **Community** | fut.gg, EA Forums posts | Direction of travel only; never sole support for a factual claim |

Where a claim rests only on a non-EA source, the agent reports say so in their
confidence column, and `qa/claim_verdicts.md` records it as a verdict.
