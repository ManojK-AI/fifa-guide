# Documentation

| File | What it is |
|---|---|
| [`legendary-playbook.md`](legendary-playbook.md) | The coaching playbook — pre-game card, the three gaps, tactics setups for both games, button tables, match log. Point-in-time export of the [live Claude doc](https://claude.ai/artifact/2edEEMC38u4mDKVqEhPxDk) |
| [`research/`](research/) | Everything the guide's content rests on: source research, bibliography, methodology, claim-by-claim verification, QA evidence |

## If you are about to research something

Read [`research/README.md`](research/README.md) first. Its coverage map says what is
already answered and its "Known gaps" section says what was already looked for and
not found. [`research/TEMPLATE.md`](research/TEMPLATE.md) has a briefing prompt to
hand any AI session so it reads the archive before spending a search budget
rediscovering what is here.

## Relationship between the three deliverables

- **`replay-room.html`** (repo root) — the interactive page: 31 animated tactical
  clips, AI scouting reports, the Scan trainer, the pre-game plan. This is what you
  open to practise.
- **`docs/legendary-playbook.md`** — the written playbook. Read-once-then-play
  material: principles, routines, settings, drills, and the match log.
- **`docs/research/`** — the evidence under both. Not for reading cover to cover;
  for looking things up and for not repeating work.

The page and the playbook are kept consistent with each other deliberately. If you
change a factual claim in one, check the other — `research/VERIFICATION_LOG.md`
records an alignment pass on 2026-10-07 that existed because they had drifted.
